# 全部 DWG 参照验收 · beta.5

所有操作默认递归可解析的 DWG 参照；清戳及显式覆盖不再仅处理输入主图。默认不限深度，共享和循环引用按路径去重。每份替换保留独立校验备份和原 DWG 格式。

## 原生宿主验证

工作区中使用公开 JTB 带戳样本及 LINE/CIRCLE/TEXT 合成副本建立：Host/Host2 → refs/Mid → refs/Leaf。Host 和 Mid 为 AC1024，Leaf 为 AC1032；所有输入均为测试副本，不包含客户数据。

清戳使用 AutoCAD 2022；发现参照、打印和复查使用 AutoCAD 2020。依赖路径为普通 refs 子目录而非 .Attach，另有共享参照。AutoCAD 导出的宿主块表也可能含嵌套依赖记录，发现及处理均去重。

| 操作 | 结果 |
|---|---|
| 单主图清戳，副本模式 | 处理 Leaf、Mid、Host 三份，前有戳后未检出；三份版本不变；原件哈希不变；生成相对路径整包 |
| 单主图清戳并覆盖 | 三份均校验备份后替换；备份哈希与处理前各文件一致，三份版本不变 |
| 单主图普通修复并覆盖 | 主图与两份参照均替换，各有一份备份，版本不变 |
| 两张主图批量修复并覆盖 | 两张主图和两份共享参照各备份一次，共四份；共享参照没有重复处理或覆盖 |
| 从覆盖后的主图再打印检查 | 自动发现并检查三份 DWG，均未检出水印 |
| 从副本整包主图再打印检查 | 三份 DWG 均可解析并完成打印，均未检出水印 |
| 参照缺失的主图清戳并覆盖 | 参照发现失败，返回非零；主图哈希不变，没有备份或替换 |

本地证据：dwg-check/xref-suite/manifest.json、verified.json、copy-result/、overwrite-result/、repair-result/、batch-result/、recheck-fixed/、bundle-recheck/、missing-result/。备份内容按每份原件 SHA-256 独立核对；验证代码与 JSON 结果保留在工作区输出目录，不将原始 DWG 提交到 GitHub。

## 处理规则

清戳按依赖顺序运行。打印只在隔离快照中重定向路径，使用已清参照候选；快照另存也保持各自版本，检查路径更新是否成功。交付 DWG 不带这些临时路径。图集有缺失或无法发现的依赖时，不启动清戳或覆盖。普通修复可保留报告与候选，但不覆盖不完整图集。

对共享参照，同一任务只备份及替换一次；批量报告可按不同所属主图重复列出参照，但备份文件是同一份。覆盖不是整图集事务，后续文件失败时已完成的替换和备份会保留。

回归测试额外覆盖：循环去重（模拟）、深度截断失败、参照失败阻止宿主、处理期间用户修改不被覆盖、单主图递归清戳、单主图连参照覆盖和逐份备份。

## 范围限制

本次原生样本为公开/合成图集，不能替代客户工程图、多布局或第三方代理对象验收；循环引用只有模拟遍历测试。绝对路径和目录外参照可以处理、按原路径备份覆盖，但不保证副本包可移植；此类路径未作为本次完整原生图集样本覆盖。打印结论仅覆盖本次输出页面，未检出不证明许可资格。

## beta.4：显式覆盖与强制备份

默认仍保留原图；仅 --overwrite 开启替换。普通修复/批量修复只覆盖主图输入，跟随参照不被隐式替换；清戳要求前后打印通过。原图旁生成唯一时间戳 .bak，SHA-256 与处理前原件一致后才允许替换；处理期间原件变化、锁文件、备份失败、版本或成品验收失败均禁止覆盖。使用同目录暂存及原子替换，保留已验证备份和成品副本；不提供整批事务回滚。

实际 AutoCAD 验收使用工作区中的专用测试副本，未覆盖公开下载原件或客户图纸。all、edustrip、batch --repair 三条 --overwrite 流程均成功，备份哈希等于处理前输入，原路径的新内容哈希等于验收成品，版本分别保持 AC1027/AC1024/AC1027。证据位于本地 dwg-check/overwrite-validation/verified.json 及对应 JSON 报告。

30 项测试通过，含备份失败/损坏、原图变化、版本变化、CAD 锁、原子替换失败、重复备份、默认不覆盖、显式覆盖和非法模式拒绝。宿主测试只覆盖上述三个场景，不承诺多进程写同一图纸时的互斥锁或突然断电恢复；用户需先关闭目标图纸。

# 第一次使用图纸医生

你需要一台已安装并激活 AutoCAD 的 Windows 电脑，以及能读取本地文件、执行脚本并加载技能的 AI 助手。首次接触这类工具，可以考虑 WorkBuddy；本项目不包含该工具的安装和操作教程，也尚未完成其中的端到端兼容验收。

## 1. 安装图纸医生

从本项目 GitHub Releases 下载 `cad-dwg-doctor.zip`。解压后保留完整 `cad-dwg-doctor` 文件夹，里面应有 `SKILL.md`、`scripts`、`references` 和 `requirements.txt`。

在你使用的助手中，通过其技能导入功能添加此文件夹；若只支持技能目录，将完整文件夹放入该工具规定的目录。不同工具的入口和目录不同，请以该工具说明为准，不要把 Codex 的目录直接用于其他工具。没有技能加载或本地脚本执行能力的聊天工具无法完成本地 DWG 处理。

添加后重新加载技能或开启新对话，发送：

> 请使用图纸医生，检查这台电脑能不能处理 DWG。先不要修改图纸；缺少运行组件时，帮我准备技能专用环境，并说明检查结果。

如果助手没有识别到图纸医生，请检查导入的是否为包含 `SKILL.md` 的完整文件夹。安装成功以助手实际读取技能并运行检查为准，不能仅以下载完成判断。

## 2. 检查能不能用

助手使用实际任务的 Python 运行 `scripts/check_environment.py`。普通检查与修复用默认模式，打印检查用 `--mode print`，清戳用 `--mode strip`。

- 缺少 Python：说明需要 Python 3.10+，由助手在宿主允许的范围内协助准备；无法安装时明确告诉用户阻碍。
- 缺少依赖：优先在技能专用虚拟环境中，使用该解释器的 `-m pip install -r <技能目录>/requirements.txt` 安装，然后重新检查。不要让设计师手选库或解释器。
- 找不到 AutoCAD：询问其安装位置，使用 `--acc` 或现有引擎配置；不自动安装或激活 AutoCAD。清戳需要识别到 2022+，未知年份不能直接视为满足。
- 检查通过：说明可以开始实际任务，同时说明尚未验证 AutoCAD 激活、临时目录访问和实际图纸。

## 3. 处理第一套图

保留原有图纸文件夹结构。向助手提供主图的完整本地路径，或整套图纸所在文件夹；不要只上传脱离参照的主图副本。

可以复制下面一句，改掉路径：

> 请用图纸医生检查并修复清理这套图纸，包括全部外部参照。图纸位置是 D:\项目图纸\主图.dwg。保留原文件，保持每份 DWG 的原版本，完成后告诉我结果放在哪里。

日常只需要说清需求：

| 你可以这样说 | 实际行为 |
|---|---|
| 帮我检查这套图 | 只读检查主图与参照，不修改原文件 |
| 帮我修复清理这套图 | 处理主图与参照，默认生成副本 |
| 检查有没有教育版打印水印 | 打印检查，并给出可复核的打印件 |
| 清除教育版打印戳记，覆盖原文件 | 前后打印复验；主图与参照每份替换前分别验证备份 |

“覆盖原文件”会涉及这套图的全部可解析参照，包括文件夹以外的参照。覆盖按文件执行；中途失败不会自动把此前成功替换的文件整批回滚，每份成功替换的文件均保留备份。

## 结果应该怎样说明

助手应依据本次报告说明：

1. **实际结果**：完成、部分完成或失败；分别统计主图与唯一参照，不重复计算共享文件。
2. **文件状态**：生成副本还是实际覆盖；覆盖了哪些文件、备份在哪里。仅 `overwrite.replaced: true` 可称已覆盖。
3. **验证情况**：各文件版本核对结果、参照是否齐全、打印检查实际覆盖范围；未检查项明确写未验证。
4. **可打开的文件**：提供成品、整包、报告、打印件和备份的实际可点击路径。未隔离重开验证的整包称“候选包”。
5. **下一步**：有问题时先给出具体可执行动作，例如“找到缺失的 结构底图.dwg 并恢复原参照路径，然后重新检查”。技术日志保留供排查。

示例格式（数字和路径必须来自本次执行）：

> 已处理主图 1 份、参照 2 份，原文件保留。三份图纸的 DWG 格式版本均与处理前一致。成品与报告见下方链接。整包尚未隔离重开，仍需复核参照加载；本次没有进行打印检查。

失败时不能用“全部完成”掩盖部分成功。打印未命中应写“本次打印未检出”，不能写成所有布局均无戳。运行前提检查通过、脚本执行成功和工程图纸验收通过是不同结论。

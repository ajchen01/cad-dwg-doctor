# 核查项清单（规则表）

级别：**错误** = 必须修　**警告** = 建议修　**提示** = 按需

| 编号 | 级别 | 检查项 | 判定口径 | 处置 |
|---|---|---|---|---|
| F01 | — | 文件格式版本 | `$ACADVER` AC1032=2018 / AC1027=2013 / AC1024=2010 / AC1009=R12 | 低版本给高版本会丢填充/约束，高给低会被降级 |
| F02 | 警告 | 插入单位未设定 | `$INSUNITS = 0` | 设成 4（毫米）；否则 xref、复制粘贴比例错乱 |
| F03 | 警告 | 代理对象 | 实体类型含 `PROXY` | 天正/探索者对象。交付通用图必须用原插件「图形导出」，**不要 DXF 往返** |
| F04 | 错误 | 教育版标记 | **只能打印出来看**：`eduprint.py check` 打成 PDF，看页面四边有没有那行 AUTODESK 水印（每边约 8 个连通块、暗 0.6~0.8%）。字节扫描、DXF 明文扫描、开图抓提示框——**三条路都已证伪** | 打印带水印，送审会被退。DXF 往返、商业版另存、删光内容**实测都洗不掉**；只有 AutoCAD 2022+ 打开另存能清（`edustrip`） |
| F10 | 提示 | 空图层 | 图层存在但该层实体数 = 0 | `-PURGE` 清掉；留少量做标准层模板也可 |
| F11 | 提示/警告 | 实体在 0 层 | 0 层实体数 | **有代理对象时降为提示**（天正对象驻 0 层属正常）；纯手工图元才需归层 |
| F12 | 提示 | Defpoints 层有实体 | Defpoints 层实体数 | 标注定义点常放此层，正常；抽查是否有手工图元被误放（不打印会整片消失） |
| F13 | 提示 | 关闭/冻结层上有实体 | 层 off/frozen 但仍有实体 | 确认是故意隐藏；否则出图缺内容 |
| F14 | 警告 | 图层名含危险字符 | 含 `= * $` 或长度 > 255 | 平台同步产生的垃圾层名，会让 xref 绑定与脚本失败 |
| F15 | 提示 | xref 携带图层 | 层名含 `\|` | 随 xref 存在，`xbind` 后才成为本图图层 |
| F20 | 提示 | 未使用的块定义 | 块未被 INSERT 引用 | `-PURGE` 可清，通常能显著减小体积 |
| F21 | 提示 | 匿名块 | `*T`（表格）`*U`（动态块）`*D`（标注） | 正常结构；数量异常多说明堆积了未用动态块 |
| F21b | 提示 | 含外部参照 | 块 flags & 4 | 确认 xref 文件随图交付，否则打开丢底图 |
| F30 | 错误 | 零长度图元 | 线起终点距离 < 1e-9；圆/弧半径 < 1e-9 | 删除。会导致捕捉错乱、选择集异常 |
| F31 | 提示 | 极短图元 | 长度 < 图形尺度 × 1e-5 | 多为误操作残留，可删 |
| F32 | 警告 | 重复图元 | 同端点/同位置同内容的实体 ≥ 2 | 打印发黑、线宽叠加；GUI 里跑 `OVERKILL` |
| F33 | 警告 | 游离图元 | 距中位中心 > max(尺度×1000, 1e5) | 误粘贴/坐标错乱；会让 `ZOOM E` 失效 |
| F40 | 警告 | 空文字 | TEXT/MTEXT 内容为空（含只剩格式码的 MTEXT 空壳） | 影响统计与批量替换，建议删。自动清理只删「确定无内容」的：空白 / 仅 `\P` 换行；格式码空壳留人工 |
| F41 | 警告 | 文字高度异常 | 高度 < 0.5 或 > 1000 图形单位 | 先确认不是整体比例错了 |
| F42 | 提示 | MTEXT 宽度为 0 | `width = 0` | 不会自动折行；要折行就得给宽度 |
| F50 | 提示 | Z 坐标不为 0 | 起点/圆心/多段线 elevation 的 \|z\| > 1e-6 | 平面图常见高程残留，`FLATTEN` 压平 |
| F60 | 提示 | 未使用的文字样式 | 无实体引用 | `-PURGE` |
| F61 | 提示 | 未使用的线型 | 无实体引用（排除 BYLAYER/BYBLOCK/CONTINUOUS） | `-PURGE` |
| F70 | 警告 | 字体文件缺失 | 样式引用的 TTF/TTC/OTF 在 `C:\Windows\Fonts` 找不到 | 换机器会替换字体导致字宽变化；**SHX 无法自动核对，需人工确认** |
| F80 | 提示 | 空布局 | 布局内实体数 = 0 | 交付前可删 |

## 尺度口径

「尺度」= 2 × 各实体到中位中心距离的 90 分位。
用中位数而不是包围盒，是因为**一个误粘贴的远点就能把包围盒撑到 1e8**，那样「超远」和「极短」两条规则会同时自我失效。

## 不做的检查（以及为什么）

| 想查的 | 为什么不做 |
|---|---|
| 标注值是否正确 | 设计判断，不是格式问题 |
| 图框是否套对 | 需要标准图框作参照，无法通用 |
| 实体重叠/自交（多段线） | 计算量随实体数平方增长，大图跑不动；交给 CAD 的 `OVERKILL` / 视觉检查 |
| 图层归属是否符合制图标准 | 需要甲方标准表，做成 skill 内固定规则会误伤 |
